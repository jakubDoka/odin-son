# Odin Son

Minimal Sea-Of-Nodes compiler backend library. Early development. Supports x64,
arm64 and wasm64.

The root of a repository contains a compiler capable of compiling a subset of
Odin. It's used for testing but can be helpfull for referencing usage code.

The actual backend is called `bac`, and has rust and c bindings, but they are
low quality for now, I have to write more documentation.
